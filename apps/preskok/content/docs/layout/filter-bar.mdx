## Usage

```tsx
import {
  FilterBar,
  FilterBarAdd,
  FilterBarChips,
  FilterBarClear,
  matchesFilter,
  type Filter,
  type FilterField,
} from "@/components/ui/preskok-ui/filter-bar"

const fields: Array<FilterField> = [
  {
    id: "status",
    label: "Status",
    variant: "select",
    options: [
      { value: "available", label: "Available" },
      { value: "sold", label: "Sold" },
    ],
  },
  { id: "price", label: "Price", variant: "number", unit: "€" },
  { id: "listed", label: "Listed", variant: "date" },
]

export function Vehicles() {
  const [filters, setFilters] = useState<Array<Filter>>([])
  const rows = vehicles.filter((vehicle) =>
    filters.every((filter) => matchesFilter(vehicle[filter.field], filter))
  )

  return (
    <FilterBar fields={fields} value={filters} onChange={setFilters}>
      <FilterBarChips />
      <FilterBarAdd />
      <FilterBarClear />
    </FilterBar>
  )
}
```

`FilterBar` holds the state and lays out its children in a wrapping row, so a search field or a
sort button can sit next to the chips. Its parts can go in any order:

| Part             | Renders                                                                                |
| ---------------- | -------------------------------------------------------------------------------------- |
| `FilterBarChips` | One chip per filter, flowing in the bar's row; `max` collapses the rest into "+N more" |
| `FilterBarAdd`   | "+ Filter" with its <kbd>F</kbd> shortcut (`shortcut` changes or disables it)          |
| `FilterBarClear` | Removes every filter; hidden when there are none                                       |

## Composing chips

`FilterBarChips` renders `<FilterChip />` for each filter, made of `FilterChipField`,
`FilterChipOperator`, `FilterChipValue` and `FilterChipRemove` (yes / no chips leave the operator
out). Pass a function to compose your own:

```tsx
<FilterBarChips>
  {({ field }) => (
    <FilterChip>
      <FilterChipField />
      {field.id === "status" ? null : <FilterChipOperator />}
      <FilterChipValue />
      <FilterChipRemove />
    </FilterChip>
  )}
</FilterBarChips>
```

The parts read their filter from `FilterBarChips`, so they only need a `className`.

## Fields and operators

Each field's `variant` decides its operators and value editor. The first operator is the default;
pass `operators` to restrict or reorder them.

| Variant   | Operators                                                                                      | Value editor                                                 |
| --------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `text`    | contains, does not contain, is, is not, is empty, is not empty                                 | Text input                                                   |
| `number`  | is between, is, is not, is less than, is at most, is greater than, is at least, is (not) empty | Number input, two for `between`                              |
| `select`  | is any of, is none of, is empty, is not empty                                                  | List; above 7 options, a search and the picked options first |
| `boolean` | (none: the chip reads "Electric · Yes")                                                        | Yes / No, picked straight from the menu                      |
| `date`    | is between, is, is before, is after, is empty, is not empty                                    | Presets and a range calendar, or a calendar                  |

Filter values are plain data, so they serialize to a URL or a request body as they are:

```ts
{ id: "price", field: "price", operator: "between", value: [10000, 25000] }
{ id: "listed", field: "listed", operator: "between", value: { start: "2026-10-22", end: "2026-11-20" } }
```

Number fields can set `numberFormat` (e.g. `{ useGrouping: false }` for years) and `unit`.

"+ Filter" asks for the field, then its operator and value in the same popover. The filter goes
into the list straight away as a dimmed chip and applies while values are picked, so `onChange`
fires with filters that have no value yet; it is dropped if the popover closes without one. Yes /
no and date presets are picked from a submenu in one step. `isFilterActive` tells whether a filter
narrows anything: filter on the server by sending the active filters, or on the client with
`matchesFilter(cellValue, filter)`.

## Translations

Every string comes from `messages`; anything left out falls back to English
(`defaultFilterBarMessages`).

```tsx
<FilterBar
  fields={fields}
  messages={{
    addFilter: "Dodaj filter",
    clear: "Počisti",
    moreFilters: (count) => `+${count} več`,
    operators: { isAnyOf: "je katerikoli od", between: "je med" },
    datePresets: { "30d": "Zadnjih 30 dni" },
  }}
>
  …
</FilterBar>
```

Dates and numbers follow the locale from React Aria's `I18nProvider`.

## Keyboard

| Key                  | Action                                                                        |
| -------------------- | ----------------------------------------------------------------------------- |
| <kbd>F</kbd>         | Opens "+ Filter" when no field is focused (`shortcut` changes or disables it) |
| <kbd>Backspace</kbd> | Removes the chip whose button has focus                                       |
| <kbd>Enter</kbd>     | Applies a text or number value and closes the editor                          |
