## Usage

```tsx
import { useState } from "react"

import {
  FilterBar,
  FilterBarAdd,
  FilterBarChips,
  FilterBarClear,
  matchesFilter,
  type Filter,
  type FilterField,
} from "@/components/ui/preskok-ui/filter-bar"

const fields: Array<FilterField> = [
  {
    id: "status",
    label: "Status",
    variant: "select",
    options: [
      { value: "available", label: "Available" },
      { value: "sold", label: "Sold" },
    ],
  },
  { id: "price", label: "Price", variant: "number", unit: "€" },
]

const vehicles = [
  { id: 1, name: "Volkswagen Golf", status: "available", price: 24900 },
  { id: 2, name: "Tesla Model 3", status: "sold", price: 39500 },
]

export function Vehicles() {
  const [filters, setFilters] = useState<Array<Filter>>([])
  const rows = vehicles.filter((vehicle) =>
    filters.every((filter) => {
      const field = fields.find((candidate) => candidate.id === filter.field)
      const cell = filter.field === "price" ? vehicle.price : vehicle.status

      return !field || matchesFilter(cell, filter, field)
    })
  )

  return (
    <>
      <FilterBar fields={fields} value={filters} onChange={setFilters}>
        <FilterBarChips />
        <FilterBarAdd />
        <FilterBarClear />
      </FilterBar>
      <ul>
        {rows.map((vehicle) => (
          <li key={vehicle.id}>{vehicle.name}</li>
        ))}
      </ul>
    </>
  )
}
```

`FilterBar` holds the filters and lays its children out in a wrapping row, so a search field or a
sort button can sit beside the chips. A filter is plain data, `{ field, operator, value }`, so it
goes into a URL or a request body as it is. "+ Filter" adds the filter as soon as a field is
picked and drops it if the popover closes without a value, so use `isFilterActive` to skip
filters that narrow nothing yet.

## Fields and operators

A field's `variant` sets its operators and value editor. The first operator is the default; pass
`operators` to restrict or reorder them.

| Variant   | Operators                                                                   | Value                               |
| --------- | --------------------------------------------------------------------------- | ----------------------------------- |
| `text`    | `contains`, `notContains`, `is`, `isNot`, `isEmpty`, `isNotEmpty`           | `string`                            |
| `number`  | `between`, `is`, `isNot`, `lt`, `lte`, `gt`, `gte`, `isEmpty`, `isNotEmpty` | `number`, or `[min, max]`           |
| `select`  | `isAnyOf`, `isNoneOf`, `isEmpty`, `isNotEmpty`                              | `string[]` of option values         |
| `boolean` | `is`                                                                        | `boolean`                           |
| `date`    | `between`, `is`, `before`, `after`, `isEmpty`, `isNotEmpty`                 | `"2026-11-20"`, or `{ start, end }` |

`FilterBarChips` renders `<FilterChip />` for each filter. Pass a function to build chips from

## Keyboard

`<FilterBarAdd shortcut="f" />` opens "+ Filter" with <kbd>F</kbd> when no text field is focused.
In a value editor, <kbd>Enter</kbd> applies the value and closes it.
