## Variants

`card` (default) frames each row, `bordered` draws one frame with dividers, and `plain` drops the frame for menu-like rows.

<ComponentPreview
  name="grid-list-variants-preskok-demo"
  description="The card, bordered and plain variants."
/>

## Rows with controls

Rows can hold their own controls, such as a switch per row. Use `bordered` for settings-style lists.

<ComponentPreview
  name="grid-list-controls-preskok-demo"
  description="Bordered grid list with a switch in every row."
/>

## Installation

```bash
npx shadcn@latest add @preskok/grid-list
```

## Usage

```tsx
import { GridList, GridListItem } from "@/components/ui/preskok-ui/grid-list"

export function Example() {
  return (
    <GridList aria-label="Items" variant="bordered">
      <GridListItem id="a">A</GridListItem>
      <GridListItem id="b">B</GridListItem>
    </GridList>
  )
}
```
