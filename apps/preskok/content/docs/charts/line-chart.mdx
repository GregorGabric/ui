## Installation

```bash
npx shadcn@latest add @preskok/line-chart
```

## Usage

```tsx
import { LineChart } from "@/components/ui/preskok-ui/line-chart"

const data = [
  { month: "January", sales: 186, profit: 80 },
  { month: "February", sales: 305, profit: 200 },
]

const config = {
  sales: { label: "Sales", color: "var(--chart-1)" },
  profit: { label: "Profit", color: "var(--chart-2)" },
} as const

export function LineChartDemo() {
  return <LineChart config={config} data={data} dataKey="month" />
}
```

## Features

- **Several series** with a shared crosshair and grouped tooltip
- **Curves** through `lineType`
- **Compact sparklines** with `grid="hidden"`, `xAxis={false}`, and `yAxis={false}`
