## Installation

```bash
npx shadcn@latest add @preskok/area-chart
```

## Usage

```tsx
import { AreaChart } from "@/components/ui/preskok-ui/area-chart"

const data = [
  { month: "January", desktop: 186, mobile: 80 },
  { month: "February", desktop: 305, mobile: 200 },
  { month: "March", desktop: 237, mobile: 120 },
]

const config = {
  desktop: { label: "Desktop", color: "var(--chart-1)" },
  mobile: { label: "Mobile", color: "var(--chart-2)" },
} as const

export function AreaChartDemo() {
  return (
    <AreaChart
      config={config}
      data={data}
      dataKey="month"
      fillType="gradient"
      lineType="monotone"
    />
  )
}
```

## Features

- **Types**: `default`, `stacked`, and `percent`
- **Fills**: `gradient`, `solid`, or `none`, with the line drawn along the top edge only
- **Curves** through `lineType` (`linear`, `monotone`, `natural`, `step`, and more)
- **Gaps** for missing values, or bridged with `connectNulls`
