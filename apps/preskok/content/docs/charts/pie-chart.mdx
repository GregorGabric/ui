## Installation

```bash
npx shadcn@latest add @preskok/pie-chart
```

## Usage

```tsx
import { PieChart } from "@/components/ui/preskok-ui/pie-chart"

const data = [
  { name: "Product", amount: 420 },
  { name: "Sales", amount: 310 },
  { name: "Support", amount: 180 },
]

export function PieChartDemo() {
  return (
    <PieChart
      centerLabel="Total requests"
      config={{
        Product: { label: "Product", color: "var(--chart-1)" },
        Sales: { label: "Sales", color: "var(--chart-2)" },
        Support: { label: "Support", color: "var(--chart-3)" },
      }}
      data={data}
      dataKey="amount"
      nameKey="name"
      variant="donut"
    />
  )
}
```

## Features

- **Pie or donut** through `variant`
- **Center label** on donuts that shows the total, or the selected slice's value
- **Slice selection** from a click or the legend
