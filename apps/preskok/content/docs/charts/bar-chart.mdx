## Installation

```bash
npx shadcn@latest add @preskok/bar-chart
```

## Usage

```tsx
import { BarChart } from "@/components/ui/preskok-ui/bar-chart"

const data = [
  { month: "January", desktop: 186, mobile: 80 },
  { month: "February", desktop: 305, mobile: 200 },
]

const config = {
  desktop: { label: "Desktop", color: "var(--chart-1)" },
  mobile: { label: "Mobile", color: "var(--chart-2)" },
} as const

export function BarChartDemo() {
  return <BarChart config={config} data={data} dataKey="month" />
}
```

## Features

- **Types**: `default`, `stacked`, and `percent`
- **Rounded bar ends** through `barProps.radius`
- **Focus fade** on hover and keyboard focus, respecting reduced motion
- **Legend selection** that highlights one series
