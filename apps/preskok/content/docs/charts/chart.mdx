## Installation

```bash
npx shadcn@latest add @preskok/chart
```

## Usage

```tsx
import { AreaChart } from "@/components/ui/preskok-ui/area-chart"

const data = [
  { day: "Mon", Desktop: 120, Mobile: 80 },
  { day: "Tue", Desktop: 200, Mobile: 130 },
]

const config = {
  Desktop: { label: "Desktop", color: "#2563eb" },
  Mobile: { label: "Mobile", color: "#60a5fa" },
}

export function ChartDemo() {
  return (
    <AreaChart data={data} dataKey="day" config={config} lineType="monotone" />
  )
}
```

## Features

- **TanStack Charts** rendering, scales, motion, and accessible focus
- **Legend** with selection filtering
- **Tooltip** with configurable React content
- **Shared helpers** for colors, axes, data shaping, and formatting
