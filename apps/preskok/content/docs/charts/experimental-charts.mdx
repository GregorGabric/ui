The existing chart components remain stable and continue to use Recharts. These
separately named components use TanStack Charts so you can evaluate the new
implementation without migrating production code.

The examples follow the [shadcn catalog](https://tanstack.com/charts/catalog/collections/shadcn)
and use Preskok design tokens (`var(--chart-1)` through `var(--chart-5)`,
`Card`, and semantic foreground/muted colors).

## Installation

Install only the experimental chart variant you want to evaluate:

```bash
npx shadcn@latest add @preskok/experimental-area-chart
```

Browse the catalog by type:

- [Area](/docs/charts/experimental-area-chart)
- [Bar](/docs/charts/experimental-bar-chart)
- [Line](/docs/charts/experimental-line-chart)
- [Pie](/docs/charts/experimental-pie-chart)
- [Radar](/docs/charts/experimental-radar-chart)
- [Radial](/docs/charts/experimental-radial-chart)
- [Tooltip](/docs/charts/experimental-chart-tooltip)

## Stability

TanStack Charts is still pre-release. Treat these components as opt-in and
expect their API to change. The unprefixed `AreaChart`, `BarChart`, `LineChart`,
and `PieChart` APIs are not changed by installing or testing them.
