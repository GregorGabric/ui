---
title: Laravel
description: Install and configure Preskok UI for Laravel
---

<Steps>

### Create project

Start by creating a new Laravel project with Inertia and React using the laravel installer `laravel new my-app`:

```bash
laravel new my-app --react
```

### Run the CLI

Run the Preskok UI init command to set up your project and install your first component:

```bash
npx preskok-ui@latest init switch
```

The command above will add the `Switch` component to `resources/js/components/ui/preskok-ui/switch.tsx`. You can then import it like this:

```tsx title="resources/js/pages/index.tsx" {1,6} showLineNumbers
import { Switch } from "@/components/ui/preskok-ui/switch"

const MyPage = () => {
  return (
    <div>
      <Switch />
    </div>
  )
}

export default MyPage
```

</Steps>
