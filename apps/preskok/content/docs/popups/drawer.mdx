## Installation

```bash
npx shadcn@latest add @preskok/drawer
```

The drawer uses the [React Aria Sheet](https://react-aria.adobe.com/Sheet), which needs `react-aria-components` 1.22.0 or later. The CLI also adds the `drawer-backdrop` and `drawer-scale-back` keyframes that keep the backdrop and stacked drawers in sync with the swipe gesture.

## Usage

```tsx
import { Drawer } from "@/components/ui/preskok-ui/drawer"

export function Example() {
  return (
    <Drawer>
      <Drawer.Trigger>Open</Drawer.Trigger>
      <Drawer.Content side="right">
        <Drawer.Header>
          <Drawer.Title>Title</Drawer.Title>
          <Drawer.Description>Description</Drawer.Description>
        </Drawer.Header>
        <Drawer.Body>Content</Drawer.Body>
        <Drawer.Footer>
          <Drawer.Close>Close</Drawer.Close>
        </Drawer.Footer>
      </Drawer.Content>
    </Drawer>
  )
}
```

## Side

`side` sets the edge the drawer is anchored to. It can be swiped back toward that edge to dismiss it. Use `left` or `right` for navigation, `bottom` for a mobile sheet.

## Snap points

`snapPoints` makes the drawer stop partially open. Each value is the visible amount, in pixels or a CSS length. The drawer opens at the first snap point and can be dragged to full height. Its content scrolls only once it is fully expanded.

## Props

`Drawer.Content` accepts the React Aria `SheetOverlay` props (`isOpen`, `onOpenChange`, `swipeDirection`, `snapPoints`, `preventDismissal`), plus:

| Prop        | Type                                     | Default    |
| ----------- | ---------------------------------------- | ---------- |
| `side`      | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` |
| `isFloat`   | `boolean`                                | `false`    |
| `isBlurred` | `boolean`                                | `true`     |
| `notch`     | `boolean`                                | `true`     |
