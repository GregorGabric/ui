## Usage

```tsx
import {
  Sheet,
  SheetContent,
  SheetTrigger,
} from "@/components/ui/preskok-ui/sheet"

export function SheetDemo() {
  return (
    <Sheet>
      <SheetTrigger>Open</SheetTrigger>
      <SheetContent>Content</SheetContent>
    </Sheet>
  )
}
```

The sheet is built on the [React Aria Sheet](https://react-aria.adobe.com/Sheet), which needs `react-aria-components` 1.22.0 or later. The CLI also adds the `sheet-backdrop` and `sheet-scale-back` keyframes that keep the backdrop and stacked sheets in sync with the swipe gesture.

## Side

`side` sets the edge the sheet is anchored to. It can be swiped back toward that edge to dismiss it. `start` and `end` follow the reading direction, so use them for navigation. Use `bottom` for a mobile sheet.

## Snap points

`snapPoints` makes the sheet stop partially open. Each value is the visible amount, in pixels or a CSS length. The sheet opens at the first snap point and can be dragged to full height. Its body scrolls only once it is fully expanded.

## Props

`SheetContent` accepts the React Aria `SheetOverlay` props (`isOpen`, `onOpenChange`, `swipeDirection`, `snapPoints`, `preventDismissal`), plus:

| Prop          | Type                                                         | Default   |
| ------------- | ------------------------------------------------------------ | --------- |
| `side`        | `"top" \| "bottom" \| "left" \| "right" \| "start" \| "end"` | `"right"` |
| `isFloat`     | `boolean`                                                    | `true`    |
| `isBlurred`   | `boolean`                                                    | `false`   |
| `closeButton` | `boolean`                                                    | `true`    |
| `notch`       | `boolean`                                                    | `true`    |
