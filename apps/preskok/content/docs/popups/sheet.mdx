## Usage

```tsx
import {
  Sheet,
  SheetContent,
  SheetTrigger,
} from "@/components/ui/preskok-ui/sheet"

export function SheetDemo() {
  return (
    <Sheet>
      <SheetTrigger>Open</SheetTrigger>
      <SheetContent>Content</SheetContent>
    </Sheet>
  )
}
```

The sheet is built on the [React Aria Sheet](https://react-aria.adobe.com/Sheet), which needs `react-aria-components` 1.22.0 or later. The CLI also adds the `sheet-backdrop` and `sheet-scale-back` keyframes that keep the backdrop and stacked sheets in sync with the swipe gesture.

React Aria positions the overlay itself. It uses `position: absolute` sized to the page instead of `position: fixed`, because iOS Safari clips fixed elements to the inner viewport. Don't add `fixed` or `inset-0` through `overlay.className`. If you do, the backdrop stops short of the status bar and address bar.

## Side

`side` sets the edge the sheet is anchored to. It can be swiped back toward that edge to dismiss it. `start` and `end` follow the reading direction, so use them for navigation. Use `bottom` for a mobile sheet. `center` opens a card in the middle of the screen that can be swiped up or down.

## Float

`isFloat` insets the sheet from the viewport edge and rounds every corner. It's on by default. Set `isFloat={false}` to attach the sheet to the edge. A flush sheet also gets overscroll padding, so pulling past the open position doesn't reveal a gap.

## Controlled

Pass `isOpen` and `onOpenChange` to `SheetContent` to open it from your own state. Without a `Sheet` trigger, one sheet can show whichever row was pressed. Keep the selected item in state after closing, so the content stays in place while the sheet animates out.

## Snap points

`snapPoints` makes the sheet stop partially open. Each value is the visible amount, as pixels or a CSS length. Percentages are relative to the sheet's size. The sheet opens at the first snap point and can be dragged to full height. Its body scrolls only once it is fully expanded.

## Stacking

Put a `Sheet` inside `SheetContent` to drill into a flow. The parent scales back behind the child, and swiping the child away returns to the parent. Only the bottom-most sheet dims the page.

## Prevent dismissal

Set `preventDismissal` to block swiping, Escape and outside clicks. The user then has to pick an action in the sheet. `role="alertdialog"` turns it on by default and hides the close button and drag handle. Use it for binding decisions, such as confirming a bid.

## Transition

React Aria opens and closes the sheet with a native smooth scroll, and the browser decides how long that takes. `transition="snappy"` (the default) uses a spring instead. It starts the spring where the sheet first appears, so the motion you see lands in about 250ms rather than 500ms. `smooth` is a softer spring, and `native` keeps the browser's scroll. Swiping, snap points and stacking are unchanged. With reduced motion, the sheet opens instantly either way.

## Animation

`swipeAnimation` takes the name of a CSS `@keyframes` rule that is scrubbed by the swipe gesture. `from` is the dismissed state and `to` is fully open. `swipeAnimationRange` limits the animation to a range of snap point indices. Define the keyframes in your stylesheet. You can also render them with a React `<style href precedence>`, which React hoists and dedupes.

## Props

`SheetContent` accepts the React Aria `SheetOverlay` props (`isOpen`, `onOpenChange`, `swipeDirection`, `snapPoints`, `preventDismissal`, `shouldCloseOnInteractOutside`), plus:

| Prop                  | Type                                                                     | Default                         |
| --------------------- | ------------------------------------------------------------------------ | ------------------------------- |
| `side`                | `"top" \| "bottom" \| "left" \| "right" \| "start" \| "end" \| "center"` | `"right"`                       |
| `isFloat`             | `boolean`                                                                | `true`                          |
| `isBlurred`           | `boolean`                                                                | `false`                         |
| `closeButton`         | `boolean`                                                                | `true`                          |
| `notch`               | `boolean`                                                                | `true`                          |
| `role`                | `"dialog" \| "alertdialog"`                                              | `"dialog"`                      |
| `preventDismissal`    | `boolean`                                                                | `true` for `role="alertdialog"` |
| `transition`          | `"snappy" \| "smooth" \| "native"`                                       | `"snappy"`                      |
| `swipeAnimation`      | `string`                                                                 | –                               |
| `swipeAnimationRange` | `{ start?: number, end?: number }`                                       | –                               |
| `overlay`             | `SheetOverlayProps`                                                      | –                               |
