# Preskok UI Components

Preskok UI is a collection of modern, accessible React components built with React Aria Components and Tailwind CSS. These components provide advanced functionality while maintaining excellent accessibility and customization options.

## Features

- **Accessible by default** - Built with React Aria Components for comprehensive accessibility
- **Highly customizable** - Styled with Tailwind CSS and Tailwind Variants
- **Type-safe** - Full TypeScript support with proper type definitions
- **Modern design** - Clean, modern aesthetics that work across all devices
- **Advanced functionality** - Rich interactive components with sophisticated features

## Installation

You can install individual Preskok UI components using the CLI:

```bash
npx preskok-ui@latest add [component-name]
```

Or install multiple components at once:

```bash
npx preskok-ui@latest add bar-list breadcrumbs button
```

## Components

The following Preskok UI components are currently documented:

- [Bar List](/docs/preskok-ui/bar-list) - Horizontal bar list for data visualization
- [Breadcrumbs](/docs/preskok-ui/breadcrumbs) - Navigation breadcrumb trails
- [Button](/docs/preskok-ui/button) - Customizable buttons with multiple variants
- [Calendar](/docs/preskok-ui/calendar) - Date selection calendar with advanced features
- [Card](/docs/preskok-ui/card) - Content containers with headers and actions

## Usage

All Preskok UI components follow a consistent API pattern and can be easily integrated into your React applications.

```tsx
import { Button } from "@/registry/preskok/ui/preskok-ui/button"

export function MyComponent() {
  return (
    <Button intent="primary" size="md">
      Click me
    </Button>
  )
}
```
