## Installation

```bash
npx shadcn@latest add @preskok/form
```

## Usage

```tsx
import { Form } from "@/components/ui/preskok-ui/form"

export function Example() {
  return <Form onSubmit={(e) => e.preventDefault()} />
}
```

## Props

- Inherits all `react-aria-components` Form props.
